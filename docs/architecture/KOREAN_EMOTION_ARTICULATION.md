# Korean Emotion Articulation

## 제품 목적

한국어 트랙의 주목적은 ‘고급 단어’를 많이 외우는 것이 아니다. 사용자가 자신의 마음을 더 정확히 알아차리고, 비슷한 감정 사이의 차이를 구별한 뒤, 상황에 맞는 한국어를 골라 자기 경험을 표현하도록 돕는 것이다.

기존의 `진짜 / 겁나 / 대박 / Yes` 같은 만능 표현 확장은 이 상위 목표를 돕는 **하위 표현력 모듈**로 둔다.

## 학습 루프

1. **감정 영역 찾기**
   - 지금 마음에 가장 가까운 큰 영역을 고른다.
   - 긍정/부정 2분법 대신 기쁨·기대·그리움·관계 상처·허전함·불안·억울함·부끄러움·복합감정 등으로 나눈다.

2. **가까운 말 펼치기**
   - 같은 영역 안의 단어를 Level 1–3으로 점진적으로 노출한다.
   - 쉬운 말과 어려운 말 사이에 우열을 두지 않는다.

3. **비슷한 말 비교하기**
   - ‘서운하다–섭섭하다–아쉽다’처럼 실제 혼동이 많은 표현을 나란히 놓는다.
   - 단어 뜻을 외우기보다 “무엇 때문에 이 말이 더 잘 맞는가?”를 질문한다.

4. **강도·원인·관계 맥락 살피기**
   - 같은 감정도 강도, 원인, 상대와의 관계, 미래/과거 지향 여부에 따라 표현이 달라짐을 학습한다.

5. **자기 문장 만들기**
   - 기본 문형: “지금 내 마음은 ___에 가깝다. 왜냐하면 ___ 때문이다.”
   - 두 번째 문형: “나는 ___해서 ___한 마음이 들었다.”
   - 감정 표현을 정답 맞히기가 아니라 자기 설명 연습으로 마무리한다.

## 대표 비교 세트

### 서운하다 · 섭섭하다 · 아쉽다
- **서운하다**: 기대했던 관계나 반응이 마음처럼 되지 않아 마음이 상하고 아쉬운 쪽.
- **섭섭하다**: 상대의 태도나 이별 같은 관계 상황에서 서운함과 아쉬움이 함께 있는 쪽.
- **아쉽다**: 무언가 부족하거나 끝나 버려 마음이 남지만 꼭 상대를 탓하지는 않는 쪽.

### 불안하다 · 조마조마하다 · 초조하다
- **불안하다**: 좋지 않은 일이 생길 것 같아 마음이 안정되지 않는 넓은 상태.
- **조마조마하다**: 앞으로 닥칠 결과를 기다리며 마음을 졸이는 상태.
- **초조하다**: 걱정과 답답함 때문에 빨리 해결되길 바라며 조급해지는 상태.

### 뿌듯하다 · 흐뭇하다 · 대견하다
- **뿌듯하다**: 나의 노력·성취 때문에 만족이 차오르는 쪽.
- **흐뭇하다**: 좋은 모습을 바라보며 따뜻하게 만족하는 쪽.
- **대견하다**: 누군가가 기대 이상으로 잘 해낸 것을 기특하게 평가하는 쪽.

### 벅차다 · 뭉클하다 · 울컥하다
- **벅차다**: 기쁨·희망·감동이 가슴에 가득 차오르는 쪽.
- **뭉클하다**: 강한 감정이 순간 마음과 가슴을 채우는 쪽.
- **울컥하다**: 참던 감정이 갑자기 치밀어 오르는 쪽.

## 아동 학습 원칙

- “그 말 틀렸어”보다 “이 말도 있어”를 사용한다.
- 감정 단어로 사람의 성격을 규정하지 않는다.
- 임상적 진단이나 정상/비정상 판단을 하지 않는다.
- 문학적·격식적 표현을 일상어보다 우월하다고 가르치지 않는다.
- 아이가 실제로 겪은 상황을 말할 수 있을 때만 자기 문장으로 연결한다.
- 말하기 싫은 감정은 건너뛸 수 있어야 한다.

## 데이터 경계

- `SOURCE_VERIFIED`: 기존 NameOnMyMind 연구 또는 국립국어원 근거와 연결된 표현.
- `DISCOVERY_ONLY`: 탐색 후보. 뜻·용례·연령 적합성을 검증하기 전에는 정식 카드로 승격하지 않는다.
- 감정 지도는 진단 도구가 아니며, 감정 점수나 사람의 성향을 판정하지 않는다.
