# 국립국어원 우선 사전 검색 V24

## 적용 범위

사용자가 승인한 공식 수집 자료를 `/learn/`의 선택적 사전 검색에 연결했다. 화면의 177개 학습 카드, 날짜 순환, 쉬운 풀이, 예문, 외국어 맥락 7개 및 기본 화면은 변경하지 않았다. 공식 자료를 새 학습 카드로 자동 승격하지 않는다.

국립국어원 우선이란 **같은 낱말 표기가 두 저장 사전에 있을 때** 국립국어원 항목을 우선 표시한다는 뜻이다. 정확히 일치하는 위키낱말사전 낱말보다 다른 국립국어원 부분 일치 단어를 위에 놓지 않는다. 정렬은 정확 일치 → 앞부분 일치 → 부분 일치이며, 같은 단계에서는 공식 자료를 먼저 표시한다.

## 자료 및 계산

원본: `content/dictionary/nikl/reviewed-source.json`. 성공한 수집 실행은 https://github.com/01chungee10snu/NameOnMyMind/actions/runs/36969611880 이다.

- 원본 SHA-256: `49385654031976a0a14cb1da2f95ca4d58a6dfd4feb581c45cfa9f95e314e33d`.
- 공식 항목 287개, 서로 다른 표기 277개. 동일 표기 내 별도 식별 항목 10쌍은 원래 동형어 번호와 target_code를 유지한다.
- 기존 위키낱말사전 표기 31,710개 중 공식 표기와 겹치는 것은 139개. 공식 자료가 추가하는 표기는 138개이며 통합 검색 범위는 31,848개 표기다.
- 수집 원본에 보존된 뜻풀이는 287개다. 기존 수집기 통계 `missing_sense_orders=313`은 요청별 처리 횟수이며, 독립된 뜻 313개를 확보했다는 뜻이 아니다.
- 공식 검색 결과의 일부만 수집되어 있고 다의어의 전체 뜻을 보장하지 않는다. 원문 전체 링크와 수집일을 함께 제공한다. 누락된 의미 번호와 품사를 추론하지 않는다.

## 실행 방식

`src/domain/official-dictionary.mjs`가 기존 사전 클라이언트와 검토된 공식 데이터 클라이언트를 결합한다. 공식 자료는 `manifest.json`, 버전이 있는 `index.json`, `dictionary.json`으로 분리한다. 원본 바이트 해시, 공개 승인 범위, 파일별 바이트 해시, 버전, 항목 ID, 출처 URL, 라이선스를 검사한다. 검색 결과 수는 각 공급원의 전체 일치 항목을 통합한 뒤 계산하고, 마지막에 표시 개수만 제한한다.

첫 화면과 타이핑 시 사전 데이터 요청을 하지 않는다. ‘사전에서 더 찾기’를 누를 때 정적 검색 자료를 로드한다. 공급원 하나가 실패하면 다른 공급원을 이용하고 실패 상태를 알린다. 잘못된 해시나 식별정보를 정상 공식 자료로 취급하지 않는다. 요청은 제한시간과 취소 신호를 지키며, 이전 검색 결과가 새 검색 화면에 나타나지 않도록 한다.

‘최신 사전 조회’는 여전히 **위키낱말사전의 실시간 공개 API**다. 국립국어원 수집 API가 브라우저에서 실시간 동작한다고 표시하지 않는다. API 키는 브라우저, 정적 데이터, 코드, 테스트, 문서에 전달하지 않는다. ‘내 문장’은 외부 사전 기능에서 읽지 않으며 전송하지 않는다.

## 출처 표시와 이용 범위

공식 항목은 국립국어원 한국어기초사전, 원문 target_code 링크, 수집일, CC BY-SA 2.0 KR을 표시한다. 번호 미제공 뜻에는 글머리표만 사용한다. 위키낱말사전 자료는 별도의 CC BY-SA 4.0 출처 표시를 유지한다. https://krdict.korean.go.kr/kor/kboardPolicy/copyRightTermsInfo 를 확인했으며, 별도 표기가 없는 텍스트 자료 조건을 적용했다. 이미지·소리·예문은 추가하지 않았다.

## 재현과 갱신

1. `npm run build:nikl` — 검토 원본과 승인 기록으로 결정론적 공개 데이터 생성.
2. `npm run check:nikl` — 원본 바이트, 승인 기록, 생성 파일 바이트 일치 검사.
3. `npm run check:g5-research && npm run check:korean-language` — 기존·신규 회귀 검사.
4. 승인된 공개 빌드와 preview staging 이후 `python3 scripts/dictionary/qa-nikl-priority.py` 실행. Python Playwright가 필요하다. 검증한 Mac에서는 `/usr/bin/python3`가 해당 설치를 갖고 있다.

후속 수집은 `dictionary-refresh.yml`의 검토 아티팩트 생성 경로를 사용한다. 현재 snapshot은 의도적으로 pin되어 있다. 새 원본을 검토하고 새 버전·출처·계수·해시·승인 기록 및 관련 검증을 함께 갱신한 후 공개한다. 현재 자료 파일을 임의로 덮어쓰거나 승인 기록 없이 자동 편입하지 않는다. 15개 기존 학습/UI/공개 카드 파일의 보존 해시는 release-review.json에 기록했다.

## 검증 한계

사전 원문과 데이터 구조, 실행, 브라우저 가독성을 검증한다. 어린이 이해도 실험이나 실제 휴대전화 기기 시험으로 간주하지 않는다. 공식 단어 277개 모두가 감정어라고 주장하지 않는다.
