# 다른 언어의 마음말 발음 안내 V25

검증일: 2026-10-08
기준 커밋: fb80aa0 (기존 한국어 학습 화면·어휘·외국어 의미 보존)

## 적용 범위

기존 7개 외국어 마음말 모두에 IPA, 한글 읽기 도움, 듣기·천천히 버튼을 추가했다.
일본어는 가나, 중국어는 성조가 표시된 병음을 함께 보여 준다.
한글은 학습용 근사 안내이며 공식 외래어 표기나 원음의 정확한 전사가 아니다.
발음의 지역·선택한 표기·연습 팁·출처·이용 조건은 기존 뜻 출처 영역에서 확인한다.
첫 화면의 한국어 뜻과 예문, 기존 세 개의 접힘 메뉴, 날짜별 어휘·외국어 의미는 그대로다.
프로토타입 HTML과 CSS를 포함한 V24 보존 대상 15개 파일의 해시 검사를 통과했다.

## 음성 처리

브라우저의 SpeechSynthesis/SpeechSynthesisUtterance를 사용한다. 추가 API 키, 패키지, 음성 파일, 마이크 권한이 없다.
버튼을 누를 때 해당 외국어 낱말만 읽는다. 일본어는 검토한 가나 읽기를 입력한다.
원어·지역이 허용 목록과 일치하는 음성만 선택하며, 그 안에서 로컬 음성을 우선한다.
웨일스어를 영어로, 브라질 포르투갈어를 유럽 포르투갈어로, 보통화를 광둥어로 대신 읽지 않는다.
‘천천히’는 합성 엔진의 rate=0.6, 기본 듣기는 rate=0.85다. 실제 시간 배율은 엔진에 따라 다르다.
같은 버튼을 다시 누르면 정지하며, 다른 버튼은 이전 재생을 취소하고 시작한다.
이동, 페이지 숨김, 해당 결과 제거, 접힘 메뉴 닫기 때 재생을 정리한다.
음성 목록의 늦은 준비, 미지원, 합성 오류, 응답 지연, 오래된 취소 이벤트를 처리한다.
사용자의 검색 입력과 ‘내 문장’을 음성 엔진에 전달하지 않는다.
온라인 기기 음성은 제공자 서버를 사용할 수 있으므로 모든 TTS가 오프라인이라는 주장은 하지 않는다.

## 실제 실행 검증

- Node 테스트 105개 + Python 테스트 8개: 113개 PASS.
- 7개 표현 × 4개 화면 폭(320/390/768/1280px): 28회 표시 검사 PASS. 가로 잘림 없음, 버튼 높이 44px 이상.
- 맥 Chromium의 실제 합성 엔진: saudade, Geborgenheit, Fernweh, Torschlusspanik, 物の哀れ, 舍不得의 start/end 이벤트 확인.
- 선택 음성: Luciana(pt-BR), Anna(de-DE), Kyoko(ja-JP), Tingting(zh-CN). 위 시험에서는 모두 localService=true.
- hiraeth: 이 맥에 cy/cy-GB 음성이 없어 VOICE_NOT_INSTALLED 안내 확인. 다른 언어 음성 호출 0회.
- 실제 느린 재생 및 Enter 키 활성화, 동적으로 생성한 국립국어원 검색 결과의 일본어 발음 재생 확인.
- 타이핑·내 문장 작성 시 앱 네트워크 요청 0회, 합성 요청 0회, 브라우저 저장소 항목 0개.
- 기존 어휘 모바일 전수 354회, 외국어 표시 14회, 사전 출처 우선순위·고장 대응 회귀 검사 PASS.
- 빌드·사전 자료 검증·개인정보 누출 검사 PASS.

Copilot 초안 뒤 정지/재생 재진입, 늦은 이벤트, 느린 버튼 이름 복원, 재생 타임아웃, 전체 이벤트 해제, 읽기 전용 발음 레지스트리를 독립 보완했다.
Copilot의 읽기 전용 추가 검토 후 중국어 원문 제목을 번체/간체로 명확히 표시하고 발음 출처의 상세 위치를 링크 설명에 포함했다.

## 근거 파일과 재현

`browser-pronunciation-qa.json`, `checks.log`, 화면 PNG 및 `regression/`의 기존 시나리오 결과.
원본 발음 자료: `content/korean-expression/world-pronunciations-v1.json` (각 항목에 원문 주소·발음 변형·확인일).
생성: `npm run build:world-pronunciation-data`
검증: `npm run check:g5-research && npm run check:korean-language`
브라우저: 공개 번들을 빌드·스테이징한 뒤 Playwright가 설치된 Python으로 `scripts/korean/qa-world-pronunciation.py` 실행.

## 검증 한계

음성 엔진의 재생 이벤트는 실제 확인했지만, 원어민의 청취 평가나 휴대전화 실기기 평가는 수행하지 않았다.
IPA의 선택 변형과 기기가 제공하는 억양은 정확히 일치한다고 보장하지 않는다.
특히 웨일스어는 테스트한 기기에 설치되어 있지 않아 실제 합성 성공으로 기록하지 않았다.
