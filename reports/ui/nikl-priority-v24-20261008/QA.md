## 결과

- 국립국어원 수집 항목 287개 / 서로 다른 표기 277개를 연결했다.
- 기존 31,710개 표기와 겹치는 139개를 중복 제거하면 138개 표기가 추가되어 총 31,848개 표기를 검색한다. 이 수치는 일반 사전 표기 수이며 검증된 감정어 수가 아니다.

- 동형어 10쌍은 각각의 원래 target_code와 동형어 번호로 구분한다. 뜻이 다른 항목을 하나로 합치지 않는다.

## 원본과 해석 범위

`content/dictionary/nikl/reviewed-source.json`은 수집 실행 36969611880에서 확보한 원본과 바이트가 같다. SHA-256은 `49385654031976a0a14cb1da2f95ca4d58a6dfd4feb581c45cfa9f95e314e33d`이다.

원본에 남은 287개 뜻풀이는 전부 원문 그대로 보존했다. `missing_sense_orders=313`은 이전 수집기의 요청별 처리 수이지 서로 다른 뜻 313개가 아니다. 이 자료는 검색 결과에서 수집한 일부 뜻이며, 표제어의 전체 의미를 담았다고 주장하지 않는다. 번호가 없는 뜻에 사전 의미 번호를 만들어 넣지 않고 글머리표로 표시한다. 누락된 품사도 추론하지 않는다.

수집일은 2026-10-02이다. 공식 텍스트에는 국립국어원 원문 링크 및 CC BY-SA 2.0 KR을 붙였다. 한국어기초사전의 공식 저작권 정책을 2026-10-08 확인했으며 미디어는 추가하지 않았다. 위키낱말사전 데이터는 별도 출처와 CC BY-SA 4.0 표시를 유지한다.

## 구현과 독립 검토

GitHub Copilot으로 최초 구현 후 감독자가 실제 코드·데이터·브라우저를 독립 검수했다. 검수에서 발견한 버전 형식 불일치, 전체 결과 수 계산, 양방향 공급원 실패 처리, 캐시 상태, 출처·해시 검증을 수정했다. Copilot 읽기 전용 추가 검토에서 확인한 위키낱말사전 캐시 얕은 복사, 누락된 샤드 해시, null API JSON 처리도 수정하고 회귀 테스트를 추가했다. 에이전트 자체 성공 보고만으로 배포 승인하지 않았다.

초기 브라우저 검사 명령은 PATH의 Python 3.14에 Playwright가 없어 중단됐다. 기존 Playwright 설치가 있는 `/usr/bin/python3`으로 실제 시나리오 전체를 다시 실행해 통과했다. 새 패키지나 비용 발생 서버는 설치하지 않았다.

## 재현

`npm run check:g5-research && npm run check:korean-language`를 먼저 실행한다. 해당 검사에 공개 산출물 초기화 과정이 있으므로 브라우저 검사와 동시에 실행하지 않는다. 승인된 public build와 research preview staging 이후 `python3 scripts/dictionary/qa-nikl-priority.py`를 실행한다. 검증한 Mac의 인터프리터는 `/usr/bin/python3`이다.

증거: `checks.log`, `independent-browser-qa.json`, `browser-qa.json`, `dictionary-browser-qa.json`, `validation-summary.json`, PNG 화면. 공개 배포 후의 확인은 `production-browser-qa.json`에 별도로 기록한다.
