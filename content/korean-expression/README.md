# Korean Language Track

## 상위 목표: KOREAN_EMOTION_ARTICULATION

한국어 트랙의 중심은 특정 유행어·강조어를 교정하는 것이 아니다.

**사용자가 자신의 마음과 감정을 더 정확히 알아차리고, 비슷한 감정의 차이를 구별하고, 상황에 맞는 한국어를 골라 자기 경험을 표현하도록 돕는 것**이 상위 목표다.

### 핵심 학습 흐름

1. 감정 영역을 찾는다.
2. 가까운 한국어 표현을 여러 개 펼쳐 본다.
3. 비슷한 말의 차이를 비교한다.
4. 감정의 강도·원인·관계 맥락을 생각한다.
5. 자기 문장으로 말한다.

현재 감정 지도:
- 22개 감정 영역
- 151개 한국어 표현
- 16개 비슷한 말 비교 세트
- Level 1–3 점진 노출
- Source-verified 117 / Discovery-only 34 구분
- 근거 연결 완료 비교 세트 16개 전체
- 공식 표제어 정규화: `샘나다` 탐색표현 → `샘내다`

주요 파일:
- `emotion-map-v1.json`
- `../../schema/korean-emotion-map.schema.json`
- `../../docs/architecture/KOREAN_EMOTION_ARTICULATION.md`

## 하위 모듈: KOREAN_EXPRESSIVE_CHOICE

`진짜 / 겁나 / 대박 / Yes` 같은 만능 표현을 다양한 표현으로 확장하는 기능은 상위 감정 언어화 목표를 돕는 하위 모듈이다.

예:
- 진짜 좋아 → 무척 좋아 / 유난히 좋아 / 대단히 좋다
- 겁나 추워 → 몹시 춥다 / 무척 춥다
- Yes! → 됐다! / 해냈다! / 쾌재!

이 모듈도 “그 말은 틀렸다”가 아니라 **“지금 상황에는 어떤 말이 더 정확할까?”**를 묻는다.

현재:
- Source-verified lexemes: 12
- Situation ladders: 6
- 후속 탐색 후보: 61

주요 파일:
- `batches/01_everyday_expression_ladders.json`
- `candidate-pool.json`

## 교육 원칙

1. **말을 금지하지 않는다**
   - ‘그 말 쓰지 마’보다 ‘이 상황에서는 이런 말도 있다’를 사용한다.

2. **어려운 말에 우월성을 부여하지 않는다**
   - 쉬운 일상어가 더 정확한 상황도 많다.
   - 격식·문학성·말맛은 사용 맥락으로 배운다.

3. **감정 단어로 사람을 규정하지 않는다**
   - “너는 질투가 많은 아이”가 아니라 “지금 질투에 가까운 마음이 들었나?”라고 묻는다.

4. **진단 도구로 사용하지 않는다**
   - 정상/비정상 감정 판정, 성격 유형화, 임상 판단을 하지 않는다.

5. **비슷한 말의 경계를 배운다**
   - 서운하다 / 섭섭하다 / 아쉽다
   - 불안하다 / 조마조마하다 / 초조하다
   - 뿌듯하다 / 흐뭇하다 / 대견하다
   - 부끄럽다 / 민망하다 / 쑥스럽다 / 멋쩍다
   - 화나다 / 분하다 / 억울하다 / 원망스럽다
   - 벅차다 / 뭉클하다 / 울컥하다

6. **자기 문장으로 끝낸다**
   - “지금 내 마음은 ___라는 말에 가깝다.”
   - “왜냐하면 ___ 때문이다.”
   - 정답을 고르는 것이 아니라 자기 경험을 더 정확히 설명하는 연습이다.

## 검증 경계

### SOURCE_VERIFIED
기존 NameOnMyMind 연구 또는 국립국어원 등 신뢰 가능한 어휘 근거가 연결된 표현이다.

### DISCOVERY_ONLY
풍부한 어휘 지도를 만들기 위한 탐색 후보다. 뜻·용례·연령 적합성을 검증하기 전에는 정식 제품 카드로 승격하지 않는다.

## 다음 연구 우선순위

- Level 1 ‘기본’ 38개는 모두 source-first 검증 완료
- Level 2 ‘확장’은 72개 중 58개 검증 완료. 후속 관용구/용례 근거로 `마음을 졸이다`, `마음에 걸리다`, `가슴이 철렁하다`를 추가 승격했으며 14개는 DISCOVERY_ONLY 유지
- Level 3 ‘섬세’는 41개 중 21개 검증 완료. 탐색형 `조바심나다`를 공식 표제어 `조바심하다`로 정규화했고, 후속 공식 색인 확인으로 `고대하다`(KRD:25588)를 추가 승격했으며 20개는 DISCOVERY_ONLY 유지
- 남은 Discovery-only 34개는 Level 2 HOLD 14개 + Level 3 HOLD 20개이며, 근거를 억지로 맞추지 않고 source-first로 순차 검증
- 16개 검증 비교세트를 실제 상황 예문·말 고르기 학습으로 확장
- 어휘 깊이(기본/확장/섬세)와 학령기 근거를 별도 축으로 관리
- 3~6학년 연구 직접 연결 21개 + 관련형 1개를 별도 표시하며, 이를 1~2학년 적합성 근거로 일반화하지 않음
- 메인 `찾기`에 SOURCE_VERIFIED 표현 중 날짜 기준으로 고정되는 `오늘의 한국어 마음말` 1개를 노출해 반복 학습 진입점을 제공
- 일일 선택은 `daily-pool-v1.json`에 잠근 116개 ID를 사용하여, 같은 날 새 어휘가 검증·배포되더라도 당일 단어가 바뀌지 않도록 운영
- 상황 입력은 자동 감정 판정에 사용하지 않고 사용자가 비교 질문과 표현을 직접 고르는 보조 장치로 유지
- 감정 영역별 삽화는 의미·문화·권리 검토 후 제작하되, 기본 생성 경로는 Ego Lite의 Google Gemini 또는 Google Flow로 제한
