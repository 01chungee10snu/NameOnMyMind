# Korean Expressive Choice Track

## 목적

이 트랙은 한국어를 ‘바르게 고치기’보다 **상황에 맞는 표현을 더 많이 알고 고르는 힘**을 기르는 데 목적이 있다.

특히 아이들이 일상에서 자주 쓰는 `진짜`, `너무`, `겁나`, `대박`, `Yes` 같은 만능어를 억지로 금지하지 않는다. 대신 같은 장면을 여러 표현으로 바꾸어 보며 다음을 구별하도록 한다.

- 정도가 얼마나 큰가
- 평소보다 특별히 두드러지는가
- 기대보다 잘한 것인가
- 결과가 충분해 만족스러운가
- 노력 끝에 성취해서 뿌듯한가
- 일이 뜻대로 풀려 환호하는가
- 원하는 만큼 충분히 즐긴 것인가

## 카드 설계 원칙

1. **금지 대신 선택지**
   - “그 말 쓰지 마”보다 “이 상황에서는 이런 말도 있어”를 기본 문장으로 한다.

2. **일대일 치환 금지**
   - `진짜` → `무척`처럼 기계적으로 바꾸지 않는다.
   - `유난히`에는 비교 기준이, `몹시`에는 강한 정도가, `제법`에는 기대 대비 평가가 있다.

3. **아이의 말에서 출발**
   - 먼저 실제로 한 말을 보여 준다.
   - 그 말이 틀렸다고 하지 않고, 같은 뜻을 더 구체적으로 말할 수 있는 선택지를 제시한다.

4. **말맛과 격식도 의미의 일부**
   - `대단히`가 `무척`보다 우월한 말이 아니다.
   - 일상성, 격식, 문학성, 장난스러움의 차이를 상황 정보로 알려 준다.

5. **사전 근거와 실제 용례를 분리**
   - `SOURCE_VERIFIED`만 카드 후보로 사용한다.
   - `DISCOVERY_ONLY`는 국립국어원 사전·말뭉치·용례 확인 전에는 제품에 노출하지 않는다.

## 첫 배치

- Source-verified lexemes: 12
- Situation ladders: 6
- 핵심 사용 장면:
  - 강한 긍정 강조
  - 강한 불편·고통 강조
  - 기대보다 잘함
  - 결과 만족
  - 성공 순간의 환호
  - 충분히 즐김

## 다음 배치 우선순위

1. `대박 / 짱 / 미쳤다` → 감탄·품질 평가 어휘
2. `진짜 예뻐` → 화사하다 / 단아하다 / 곱다 / 우아하다 / 눈부시다
3. `진짜 재밌어` → 흥미롭다 / 흥미진진하다 / 유쾌하다 / 재치 있다
4. `진짜 맛있어` → 맛의 감각을 구체화하는 미각·식감 어휘
5. `좋아 / 싫어` → 호감·만족·불편·거부의 세부 감정어
6. `몰라 / 그냥` → 생각의 불확실성·유보·추측을 표현하는 어휘
